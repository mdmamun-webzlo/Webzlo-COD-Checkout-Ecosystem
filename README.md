# Webzlo COD Checkout Ecosystem

🚀 A powerful all-in-one WooCommerce One Page Checkout plugin for WordPress. Create high-converting single-page checkout experiences, recover incomplete orders, prevent fraudulent orders, and integrate directly with Steadfast Courier (Packzy API).

---

## ✨ Features

### 🛒 One Page Checkout
- Elementor compatible checkout widget
- Single Page Checkout for WooCommerce
- AJAX checkout
- Buy Now / Direct Checkout
- Simple & Variable product support
- Responsive 50/50 layout (Product Image + Checkout Form)
- Mobile optimized

### 📦 Product Layout
- 50% Product Image
- 50% Checkout Details
- Product Title
- Product Price
- Short Description

- Order Summary

# 📥 Installation

1. Upload the plugin to:

```
/wp-content/plugins/
```

2. Activate **Webzlo COD Checkout Ecosystem**.

3. Configure the plugin:

```
COD Ecosystem → Settings
```

4. (Optional) Configure Steadfast Courier:

```
COD Ecosystem → Steadfast Courier
```

5. Add your API Key and Secret Key.

6. Add the Elementor Checkout Widget or use the provided shortcode.
